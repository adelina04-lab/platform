# Отложенное

Готовые куски, снятые с сайта до того, как будут выполнены условия для их
публикации. Это не черновики и не мусор: код дописан и проверен, ждёт только
юридической части.

| Файл | Чего ждёт |
|---|---|
| `contact-form.tsx` | форма собирает персональные данные, а значит нужны уведомление в Роскомнадзор, опубликованная политика и HTTPS |
| `politika-page.tsx` | публиковать политику, пока собирать нечего, незачем; в ней три места помечены ЗАПОЛНИТЬ — ФИО, ИНН и почта оператора |
| `../../deploy/drafts/form.php` | обработчик формы на PHP вместе с образцом настроек |

Пока на сайте только телефон — он персональных данных посетителей не собирает,
и никаких обязанностей не порождает.

Чтобы вернуть: файлы кладутся обратно (`politika-page.tsx` → `app/politika/page.tsx`,
`contact-form.tsx` → `components/`, `form.php` → `deploy/public/`), в `upload.sh`
возвращается копирование `deploy/public`.
