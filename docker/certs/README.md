# Локальные корневые сертификаты

Папка нужна только тем, у кого TLS-трафик перехватывает антивирус или
корпоративный прокси (Kaspersky, Zscaler и подобные). Без доверия к их
корневому сертификату `npm ci` внутри контейнера падает с
`self-signed certificate in certificate chain`.

Положите сюда корневой сертификат в формате PEM с расширением `.crt` — образ
подхватит его автоматически. Сами сертификаты не коммитятся: они относятся к
конкретной машине, а не к проекту.

На Windows с Kaspersky сертификат обычно уже выгружен для Node — путь лежит в
переменной окружения `NODE_EXTRA_CA_CERTS`:

```bash
cp "$NODE_EXTRA_CA_CERTS" docker/certs/local-root-ca.crt
```

Если перехвата нет, папку можно оставить пустой — сборка пройдёт как обычно.
